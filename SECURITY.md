# Security Policy

EduNexus holds school and learner data for Kenyan schools, including data about children. We take reports seriously and are grateful for them.

## Reporting a vulnerability

**Please do not open a public issue.** Report privately through either channel:

- **GitHub:** [Report a vulnerability](https://github.com/jashor254/edunexus-cbe-analyzer/security/advisories/new) (private advisory; preferred)
- **Email:** support@edunexus.co.ke, with "SECURITY" in the subject

Please include what you found, where, how to reproduce it, and the impact you expect.

## What to expect

- Acknowledgement within **3 working days**
- An initial assessment within **7 days**
- Credit in the fix notes, if you'd like it

## Scope and ground rules

In scope: this repository and the production app at edunexus.co.ke.

When testing, **do not access, modify or keep any real learner, parent or teacher data**. Use your own accounts only. Stop as soon as you can demonstrate the issue, and do not run denial-of-service, spam or social-engineering tests. Good-faith research within these rules is welcome, and we will not pursue it.

## Supported versions

Only the current `main` branch (what is deployed to production) receives security fixes.
