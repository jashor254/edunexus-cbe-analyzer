# /demo presentation screenshots

Static images for the reviewer presentation at `/demo`. Nothing else reads this
folder, and nothing here is generated by the application.

## Expected files

The presentation looks for these exact filenames. Any that are missing render
as a labelled "Screen not attached" panel naming the file it expected — product
UI is never drawn or approximated to fill the gap, so a missing screenshot is
visible and honest rather than silently faked.

| Filename | Slide | Shows |
|---|---|---|
| `learner-blueprint-where-we-stand-today.png` | 4 — Learner Blueprint | The Blueprint's "Where We Stand Today" view |
| `learner-blueprint-how-we-help-next.png` | 5 — From insight to action | The Blueprint's "How We Help Next" view |
| `learning-compass-session.png` | 5 (alternate) | A Learning Compass session |
| `teacher-documents-workflow.png` | 6 — Teacher workflow | Scheme of Work → Lesson Plans → Record of Work |
| `teacher-dashboard.png` | 6 (optional) | Teacher dashboard, if useful |
| `career-intelligence.png` | 7 — Beyond today's marks | Career Intelligence: strengths, growth areas, fields to explore |

The filename → slide mapping lives in `lib/demo/presentation.ts` (`DEMO_ASSETS`).

## Requirements

- **Real product screens only.** Capture them from the running application. Do
  not mock, redraw, retouch beyond cropping, or regenerate them.
- **Reference-school / test data only.** The presentation carries the footer
  line "Product screens use reference-school / test data." That line must stay
  true — do not capture a real beta learner's record.
- **No personal data.** No real learner names, guardian contacts, phone numbers,
  emails or school identifiers.
- Roughly 2400px wide, PNG, captured at a 2x device pixel ratio if possible.
  The frame renders them at up to 1100px CSS width.

## Open Graph image

The layout declares Open Graph metadata but no image, because no approved
branded preview asset exists in the repo. If one is added, reference it from
`app/demo/layout.tsx` — do not point it at a product screenshot.
