# Potential Ideas

A holding area for product/GTM ideas that are worth remembering but **not worth building yet**. Nothing in this folder is a commitment, a roadmap item, or a plan — it's a place to write an idea down well enough that it isn't lost, without treating it as approved scope.

## Rule for anything filed here

We only move an idea out of this folder and into real build work when there's **evidence it can work** — a real teacher/parent/NGO asking for it, a pilot behavior pattern that points at it, a concrete blocker it removes — not because it sounds good in the abstract. Matches the standing charter: small trustworthy work over speculative capability, evidence before architecture (see `docs/edunexus-operating-manifesto.md`, the Foundation Freeze in memory).

## Format

One file per idea:
- **What it is** — one paragraph, plain language
- **Why it might matter** — the real problem it would solve, if any
- **What evidence would justify building it** — the specific signal we're waiting for
- **If we ever build it — layered path** — cheapest/safest slice first, so if evidence ever arrives we don't have to redesign from scratch
- **Status** — `idea` (default) / `watching for evidence` / `evidence found — ready to scope` / `shelved`
