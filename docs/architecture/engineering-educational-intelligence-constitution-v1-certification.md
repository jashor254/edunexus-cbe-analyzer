## Remaining Known Limitations

These are not defects requiring correction — they are honestly-scoped boundaries the hardening pass deliberately did not attempt to close, consistent with the stress test's own classification of them as Future Research rather than patchable gaps:

- **Evidence integrity under deliberate human fabrication** (individual or collusive) has no defense mechanism in the current constitution — named as unresolved (correction 9), not solved. Any manuscript section touching evidence integrity must say so plainly rather than imply the Instrument Validity Gate or ECM's corroboration requirement already covers this; they don't.
- **The evidence-scarcity/stakes-severity inversion** for displaced and refugee learners is named (correction 13) but not architecturally resolved — the constitution currently treats this case identically to ordinary cold start, which is consistent but not necessarily sufficient given the elevated stakes.
- **The exact Source Reliability Table** (which source types rank where) remains deliberately undetermined, per the Blueprint's own §18 — a judgment call for the archive-mining and drafting phase, not the constitution.
- **The precise automation/non-automation boundary** (which decisions may be fully automated versus require the named human locus) remains a Chapter 4.2 design-principle question by original design, not an axiom-level answer — this was a deliberate scoping decision from the original axiom audit, reconfirmed rather than revisited here.

None of these limitations block drafting. Each has an assigned home (Chapter 4.5 or 4.2) where the manuscript will state the limitation honestly rather than paper over it — which is itself the discipline's own standard, applied to itself.

## Constitutional Stability Assessment

**Does any contradiction remain?** None found. The consistency audit (below) checked every cross-reference the hardening pass touched and found the derivation chains intact: every axiom still supports the frameworks the dependency map (§7) says it supports; ECM, the EIL, the Gate, and the Invariant reference each other correctly and non-circularly; no term now has two competing definitions.

**Does any ambiguity remain that would affect implementation?** The fifteen ambiguities the stress test found as implementation-blocking have been resolved with concrete, specific rules (independence defined structurally; precedence stated explicitly; the Invariant's two clauses now both machine-checkable). The remaining limitations listed above are scoped absences of a solution, not ambiguity about what the current rules mean.

**Does any section require reopening before writing begins?** No. Every correction was a strengthening amendment inside an existing section (§11's subsections, specific axiom notes, the Chapter 4.5 and Preface specs) — no section's fundamental shape changed, and none needs to change further before drafting.

**Can two independent engineering teams now build substantially the same Educational Intelligence System from this Constitution alone?** More confidently than before this pass, for the specific mechanisms that were tested: two teams implementing ECM would now agree on what counts as independent corroboration, what the recency/volume precedence is, and how cold-start priors are labeled — these were exactly the kind of divergence-risk the Educational Test flagged as a threat to "one shared discipline," and they're now closed. Teams would still make independent, and likely differing, judgment calls on the deliberately-unresolved items above (the automation boundary, the Source Reliability Table's exact ranking) — but those are marked as intentional latitude, not accidental ambiguity, which is the correct state for a constitution to leave them in.

**Is this Constitution stable enough to remain unchanged while an entire book is written from it?** Yes, with the explicit exception the certification format itself allows: objective typographical corrections only. Everything a Chapter 1–4 draft will need — the axioms, ECM in full formal detail, the EIL diagram, the Gate, the Invariant, the pattern catalog format, the chapter template, the dependency map — is now specified in one place, hardened against the specific attacks a rigorous adversarial pass could construct, with its own remaining limitations named rather than hidden.
