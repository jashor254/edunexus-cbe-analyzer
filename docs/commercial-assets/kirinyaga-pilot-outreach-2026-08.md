# Kirinyaga Pilot Outreach — August 2026 intake

**Goal**: 10 pilot schools running EduNexus by school opening, 2026-08-24. **Target**: Kirinyaga County first (public secondary/junior secondary + private junior/senior schools), expand to surrounding counties only after Kirinyaga results come in — per founder decision 2026-07-21.

This is a Kirinyaga-specific instance of `founder-outreach-playbook.md` — use that file for the full stage-by-stage process (Discovery, Demo, Follow-up, Pilot Invitation). This file only holds the channel-ready openers, adapted for this specific push, plus the response-driven narrowing rule.

**Narrowing rule**: not every school contacted will reply. Contact broadly across Kirinyaga first; the 10 pilot slots go to whichever schools actually respond and move through Discovery — don't pre-select 10 targets before knowing who's responsive.
