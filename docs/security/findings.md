### Known limits of the gates (deliberate, start simple)

- The route-auth gate checks guards **per file**, not per exported handler. A file with a guarded `POST` and an unguarded `GET` passes. A follow-up could add per-handler analysis.
- The Supabase advisor endpoint is experimental. The gate fails, rather than passes, if its response changes shape.
